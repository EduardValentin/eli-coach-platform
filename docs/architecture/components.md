# Components

Header: date 2026-09-15, commit 148d594f, scope apps/platform/src, apps/platform/db, packages/{config,content,db,domain,infrastructure,ui}/src plus the enforcement layer (eslint.config.mjs, tools/lint-boundaries.test.mjs, workspace package.json export maps, tsconfigs, vite/react-router/vitest configs), mode audit.

A component is a group of units behind one published surface that tooling enforces. Workspace packages are enforced by their `package.json` export maps (a deep import does not resolve). App-level folders are enforced only by ESLint `no-restricted-imports` / `no-restricted-syntax` regions R1 to R7 in `eslint.config.mjs`, proven by `tools/lint-boundaries.test.mjs`; a crossing fails `pnpm lint`, not the build. Nothing is a release unit: every package is `private` and consumed as `workspace:*` by path. Tests are the outermost pseudo-ring, not a component.
